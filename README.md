# 5STACK

O 5STACK é uma plataforma desenvolvida para facilitar a formação de equipes no Valorant. O projeto surgiu a partir de um problema comum na comunidade: encontrar jogadores compatíveis para completar um time e disputar partidas competitivas de forma organizada.

A plataforma permite que os usuários criem perfis com informações relevantes para matchmaking, tornando a busca por companheiros de equipe mais rápida e eficiente.

## Funcionalidades

- Cadastro e autenticação de usuários
- Criação de perfil de jogador
- Exibição de:
  - Rank
  - Função principal (Duelista, Controlador, Iniciador ou Sentinela)
  - Estilo de jogo (Casual ou Competitivo)
  - Idioma
- Busca de jogadores através de filtros
- Sistema de compatibilidade entre jogadores
- Avaliação e reputação dos usuários
- Formação de equipes para partidas ranqueadas

## Objetivo

Reduzir o tempo gasto procurando jogadores em grupos de Discord, redes sociais e comunidades externas, oferecendo uma plataforma centralizada para conectar jogadores com perfis compatíveis.

## Tecnologias

Este projeto está sendo desenvolvido utilizando:

- HTML
- CSS

> As tecnologias serão alteradas e expandidas durante o desenvolvimento do projeto.

## Problema Resolvido

Atualmente, muitos jogadores encontram dificuldades para completar equipes ou acabam jogando com pessoas incompatíveis em termos de comunicação, nível de habilidade e objetivos dentro do jogo.

O 5STACK busca solucionar esse problema através de um sistema de matchmaking baseado em informações relevantes do perfil de cada jogador.

## Público-alvo

- Jogadores de Valorant
- Equipes competitivas
- Grupos de amigos que precisam completar um time
- Jogadores que desejam evitar experiências negativas em filas solo
